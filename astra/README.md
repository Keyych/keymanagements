# Astra — talent page

A responsive, buildless page for Astra (voice actor), represented by Key Managements.

Cloudflare Pages project: `astra`, with `astra.keymanagements.org` attached. Pushes to `main` auto-deploy. Deploy the contents of this directory as the document root.

## Preview

From the repository root, run `python3 -m http.server 4347 --directory astra`.

## Content

From Astra's details: voice actor, gothic style, dark blue / purple palette, five boundaries, VA email (xx.astra.va@gmail.com) and Cash App ($xxastra). The enquiry form opens an email draft to her VA email; nothing is sent automatically.

No artwork yet — art is to be generated separately and added to `assets/`.

Fonts: UnifrakturMaguntia, Cormorant Garamond and Manrope, hosted locally (licenses in `assets/fonts/`).
