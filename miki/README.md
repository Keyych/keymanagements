# Miki — King of Beans

Buildless talent page for Miki, King of the Bean Kingdom: voice actor, maker of the bean games (Bean Snake, Bean Crush on mini-beans.com) and owner of Beans Digital.

Cloudflare Pages project: `miki`, with `miki.keymanagements.org` attached. Pushes to `main` auto-deploy. Deploy this directory as the document root.

## Preview

From the repository root, run `python3 -m http.server 4348 --directory miki`.
